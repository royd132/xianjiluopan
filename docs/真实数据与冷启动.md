# 真实数据、冷启动与证据边界

> 状态日期：2026-08-21

## 1. 三种运行模式

| 模式 | 数据合同 | 失败行为 |
|---|---|---|
| `mock` | 确定性品类 × 市场画像，所有证据标记 `evidence_kind=mock` | 始终可离线运行 |
| `hybrid` | 优先使用本地公开数据和 Qwen；模型失败时允许规则抽取，缺少痛点时才回退冷启动画像 | 回退范围写入 `mock_scope` |
| `real` | 公开数据缓存完整、Qwen 可用、抽取结果至少回指一个输入评论 ID | 任一硬条件失败即拒绝，不静默降级 |

Collector 不直接持有 Provider。它依据任务模式调用 Harness 注册的 `mock_data / hybrid_data / real_data` 工具，因此真实能力仍受 Capability Guard、超时、Trace、组件快照和 Provider generation 管理。并发的 Mock 与 Real 任务不会通过共享可变 Provider 串线。

## 2. BR × 自动宠物喂食器证据链

真实演示链路已经跑通：

- 4 个 ECB 汇率序列，最新 2026-08-20；
- BR HS8509 的 UN Comtrade 年度进口数据；
- NY Fed GSCPI 月度供应链压力；
- World Bank / UNCTAD LSCI 航运连接度基线；
- 50 个严格匹配的自动喂食器商品元数据，其中 23 个有有效价格；
- 75 条与这些商品 ASIN 关联的真实评论；
- Olist `pet_shop` 的 650 条葡语评论与 1,710 个历史订单；
- Qwen 真实调用，模型只返回 review ID，引用原文由代码从输入记录取回。

价格卡使用 `amazon_2023_listing_snapshot`，不会把 2023 快照写成今日实时竞品价。Olist 价格作为巴西历史成交参考。当前竞品 listing 覆盖率不可得时，竞争卡输出“审计 20 个现售商品”的验证任务，不输出伪造的 `0/10` 空位。

## 3. 证据模型

`EvidenceItem` 区分：

- `source`：汇率、贸易、指数、商品快照和原语评论；
- `derived`：由 Qwen/规则从源记录抽取的痛点；
- `mock`：仅用于离线结构演示。

真实门禁要求每张卡至少 3 条已核实源证据。若目标市场存在原语数据，还要求至少 1 条非英语源证据。翻译文本不计作原语源证据。

## 4. Qwen Grounding

评论在进入模型前被赋予本次调用内的 ID。Prompt 明确把评论声明为不可信数据，并禁止执行评论中的指令。模型输出只允许包含痛点类型、中文标签、支持该痛点的 review ID 和机会提示。代码会：

1. 丢弃不存在的 ID；
2. 用有效 ID 数量计算 mentions，不接受模型自报计数；
3. 从原输入取回引用，不接受模型生成 quote；
4. 记录模型、Adapter 版本、Prompt SHA-256 和源商品 ID；
5. 无有效回指时让 `real` 任务失败。

## 5. 尚未伪装成已完成的部分

- 当前竞品报价与 Top 20 listing 审计；
- Google Trends 官方数据；
- 马来西亚原生马来语商品评论；
- 授权社媒连续监控；
- 商家真实审核样本驱动的 Prompt/Skill 演进。

这些缺口不会删除多市场、多 Agent 或受控自进化架构。它们以 Provider、Model Adapter、Evaluation Dataset 和定时任务的形式继续接入；在数据可用前，系统宁可降低置信度或要求人工验证，也不把模板值包装成市场事实。
