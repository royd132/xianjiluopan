## 技术路线摘要

```mermaid
flowchart TB
    WEB["React"] <-->|"REST + SSE"| API["FastAPI"]
    API --> COORD["Coordinator"]
    COORD --> BOARD["CollaborationBlackboard"]
    COORD --> HARNESS["Harness"]
    BOARD --> AGENTS["Collector / Review / Market / Supply / Decision / Safety"]
    HARNESS --> TRACE["Trace"]
    HARNESS --> MEMORY["SQLite Memory"]
    HARNESS --> CHECKPOINT["Checkpoint"]
    AGENTS --> CARDS["四类决策卡"]
    CARDS --> HITL["人工复核"]
    HITL --> MEMORY
```

核心代码位于 `backend/foresight/`。默认 Mock 模式不需要外部模型或数据源，适合稳定演示和测试；真实模式通过统一 Provider 与 Model Adapter 接入。
