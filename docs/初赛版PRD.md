# 先机罗盘初赛执行版 PRD

本文件是完整 PRD 的执行摘要。完整需求见 [PRD_先机罗盘_v1.0.md](PRD_先机罗盘_v1.0.md)。

## 1. 产品目标

面向缺少海外研究团队的中小卖家，在数据就绪后 60–90 秒内，将多源市场信号转化为 `Go / Validate / Stop` 判断，以及选品、定价、竞争和最小市场验证四类可执行决策卡。每张卡均可追溯、可过期、可证伪、可人工复核。

## 2. 核心流程

```text
输入品类与市场
→ Collector 采集
→ 评论/市场/供应链 Agent 并行分析
→ Decision Compiler 生成四卡
→ Safety Evaluator 闸门校验
→ SSE 呈现进度和结果
→ 人工复核
→ 正负案例沉淀
```

## 3. 四类决策卡

| 卡片 | 回答问题 |
|---|---|
| 选品方向 | 做什么子方向、切哪个市场、用什么差异点 |
| 定价策略 | 进入价格带、锚定价、毛利假设和调价触发器 |
| 竞争打法 | 攻击什么痛点、如何表达、如何防御跟进 |
| 最小市场验证 | 找谁、在哪验证、验证什么、需要多少样本、什么情况下停止 |

强制字段：行动指令、置信度、至少三条证据、验证动作、至少一项失效条件、数据源、采集时间、AI 标记和人工复核状态。

## 4. 多 Agent 与 Harness

Agent 通过 CollaborationBlackboard 发布 Artifact 和事件，不直接互调。Harness 为所有 Agent 提供 Trace、Memory、Checkpoint、工具白名单和评测闸门。

## 5. 当前实现

- 六类 Agent 和阶段并行编排；
- FastAPI REST + SSE；
- 四卡 Pydantic Schema；
- 确定性 Mock Provider；
- 多语言痛点与供应链信号；
- 三阶段 Checkpoint；
- SQLite 长期记忆；
- 反馈飞轮 Layer 1/2；
- React 工作台与离线降级；
- CLI 报告和自动化测试。

## 6. 验收标准

| 编号 | 验收项 |
|---|---|
| AC-01 | 离线运行一次任务并生成四张卡 |
| AC-02 | 事件序列包含任务、Agent、Artifact、Checkpoint 和完成事件 |
| AC-03 | 每张卡不少于三条证据并包含非英语证据 |
| AC-04 | 每张卡包含验证动作和失效条件 |
| AC-05 | 前端可消费 SSE，并在后端不可用时降级 |
| AC-06 | 采纳/驳回/待议可写入长期记忆 |
| AC-07 | CLI 可生成 JSON 报告 |
| AC-08 | 后端测试与前端构建通过 |

## 7. 演进范围

真实数据 Provider、模型 Adapter、向量数据库服务化、任务队列和 Layer 3 模型训练属于后续工程增强。它们已有明确接口和架构位置，但不冒充当前已经完成。
