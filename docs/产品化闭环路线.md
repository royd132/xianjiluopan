# 先机罗盘产品化闭环

先机罗盘的核心不是生成一份研究报告，而是把跨境新品的首单决策变成一个可执行、可追踪、可停止的作战空间。

## 当前已落地的闭环

- 决策结果写入持久化运行账本，历史报告可按工作空间查询；
- 工作台提供 Demo / Pilot 工作空间切换，研究、历史记录和监控订阅按 workspace_id 隔离；
- STOP 确认、人工覆盖、卡片复核和执行任务状态都有审计事件；
- 单位经济模型覆盖产品、包装、国内段、国际段、关税、VAT/GST、平台费、支付费、广告费和退货准备金；
- 决策契约自动生成供应商、Listing、验证和数据回填任务；
- SellerSprite ASIN 只接受真实来源证据，不从 Mock 或普通记录 ID 猜 ASIN；
- 缓存快照与实时响应分开标记，过期来源在数据登记册中可见。

## 用户主流程

```text
创建工作空间
→ 填写品类、市场、平台、预算和成本
→ 连接合法数据源并查看覆盖缺口
→ 生成 Go / Validate / Stop
→ 把执行任务分配给成员
→ 收集样本、意向率、痛点确认率和 CPC
→ 通过或停止首单
→ 监控变化并触发局部重算
```

## 试点前必须具备

1. 工作空间成员、角色和数据隔离；
2. 至少一个目标平台的合法实时/近期数据连接；
3. 供应商报价、MOQ、交期和样品记录；
4. 目标市场税费、平台费、物流和退货假设；
5. 验证任务的负责人、截止时间、素材链接和结果回传；
6. 定时快照、通知、告警确认和重算记录。

## 产品指标

- 首次输入到首版决策的完成率；
- 每个结论拥有源记录的比例；
- 用户补齐真实成本后的比例；
- 从报告到验证任务启动的转化率；
- 14 天内完成验证的任务比例；
- STOP 后避免的库存投入金额；
- 结论在复盘中的采纳率和校准误差；
- 数据源失败、过期和回退的可解释率。

## 边界

SellerSprite、Amazon、Shopee、TikTok Shop、Lazada 和 Mercado Livre 只作为获得授权后的上游数据源。研究包 JSON 用于留档或内部工作流；ASIN 仍需按目标平台的产品库/插件流程继续处理。系统不代替税务、合规、采购或平台规则审核。
