# 先机罗盘：产品与商业价值

> 版本：v1.3 · 2026-08-24
> 核心场景：跨境新品首单前的证据驱动进入决策

## 1. 产品切口

先机罗盘不从“监控全球所有数据”起步，而是先解决一个高频、高风险、结果可验证的决策：

> 当中小跨境卖家准备付样品费、开模、下首批订单或投入广告时，这个品类是否值得进入这个国家；如果值得，先卖什么、卖多少钱、攻击哪个空位、找谁验证？

传统选品工具提供榜单和指标，通用大模型提供文字建议，但最后的 `Go / Validate / Stop` 仍由卖家凭经验拼装。先机罗盘把多源数据编译为选品、定价、竞争和最小市场验证四张决策卡，并强制附带证据、有效期、反向条件和人工复核状态。

## 2. 典型用户

### 核心用户

- **核心用户**：1–5 人、缺少海外本地研究团队、准备把成熟供应链带入陌生市场的中小跨境卖家。

工厂型卖家、代运营和出海服务商属于后续扩展客户。

### 暂不优先

- 已拥有完整数据团队和内部 BI 平台的大型品牌；
- 需要自动交易、自动采购或无人审批调价的高风险流程；
- 完全依赖私有平台数据且无法获得授权的场景。

## 3. 商家工作流

| 阶段 | 商家问题 | 产品输出 | 商家动作 |
|---|---|---|---|
| 机会初筛 | 当地需求是否增长 | 趋势、进口和评论交叉证据 | 决定是否进入验证池 |
| 样品定义 | 做什么差异才不卷价格 | 选品卡与原语隐性痛点 | 修改规格并询价 |
| 单位经济性 | 什么价格能支撑利润 | 定价区间与物流阈值 | 计算首批订单上限 |
| 上架表达 | 首屏应该证明什么 | 竞争卡与可验证卖点 | 制作对比素材和详情页 |
| 备货闸门 | 谁愿意先买 | 最小市场验证卡：人群、渠道、样本量、验证问题与停止线 | 30 份意向 + 5 次深访 |
| 上线后 | 什么时候旧结论失效 | 反向条件与监控清单 | 重新计算、观察或停止 |

产品原则是**先验证再备货**。AI 不替商家承担采购责任，而是降低因信息碎片、语言障碍和过度自信导致的错误投入。

## 4. 可量化价值

以下均为试点目标，不是已经取得的经营结果：

| 指标 | 基线 | 首轮目标 | 证明方式 |
|---|---:|---:|---|
| 单品类 × 单市场研究时长 | 2–3 个工作日 | 数据就绪后 90 秒内生成首版；端到端 2 小时内完成复核 | 系统 Trace 与人工计时 |
| 核心建议证据绑定率 | 依赖人工整理 | 100% | 结构门禁自动校验；真实模式追加证据核验门禁 |
| 非英语评论进入决策的比例 | 经常被摘要或忽略 | 每个任务至少 1 组原语证据 | Evidence Schema |
| 备货前最小验证完成率 | 无固定流程 | 80% 的试点任务完成验证计划 | 卡片复核与任务记录 |
| 决策返工可定位率 | 依赖聊天和个人记忆 | 100% 关联证据、组件版本和反馈类型 | Run Ledger / Component Snapshot |

首轮不以 GMV 作为唯一指标，因为 GMV 同时受供应链、投放和运营影响。先验证系统能否提高决策速度、证据质量与停止错误项目的能力。

## 5. 试点设计

计划招募 10 位中小跨境卖家，覆盖 3 个品类和 3 个目标市场。每位卖家选择一个真实的新品立项任务：

1. 先记录其原有研究耗时、判断和依据；
2. 使用先机罗盘生成四张决策卡；
3. 由卖家逐卡采纳、待议或驳回，并标注原因；
4. 完成最小市场验证，而不是直接下大货；
5. 两周后复盘哪些结论仍成立、哪些条件已经触发。

核心评测包括任务完成时间、证据覆盖、卡片采纳率、驳回原因分布、最小验证完成率和停止证据不足项目数。负面反馈会进入受控演进流程，但不会直接改写线上策略。

## 6. 为什么需要多 Agent 与 Harness

技术架构对应的不是“角色越多越先进”，而是跨境决策中的不同风险：

| 业务风险 | 技术机制 |
|---|---|
| 评论语义、价格统计和物流阈值混在一次生成里 | 专业 Agent 分工与结构化 Artifact |
| 一个 Agent 失败导致任务重跑、上下文过期 | Node Runtime 与 Checkpoint |
| 数据源或模型热更新后旧报告无法复现 | Component Snapshot 与 Provider generation |
| 新插件扩大工具权限 | Scoped Registry 与 Capability Guard |
| AI 给出漂亮但无依据的建议 | Evidence Schema、结构门禁与真实证据核验门禁 |
| 负反馈直接改 Prompt，造成新回归 | Validation/Holdout、人工激活与父版本回滚 |

因此，Harness 是“采购建议为什么值得被信任”的技术底座，而不是独立于产品价值的架构展示。

## 7. 冷启动策略

当前原型保留多品类 × 多市场的确定性 Mock，同时提供 Hybrid 与 Real：

- `mock`：离线演示，所有证据标记为 Mock；
- `hybrid`：公开数据优先，模型失败才允许规则抽取，回退范围必须披露；
- `real`：要求数据缓存、Qwen 与源记录回指全部成功，否则拒绝输出。

BR × 自动宠物喂食器已用商品级 Amazon 价格/评论、Olist 葡语评论与成交、Comtrade、汇率、GSCPI 和 LSCI 替换主要 Mock 信号。当前 listing 竞品覆盖率仍不可得，因此系统把竞争打法降为待验证假设，并生成 20 个现售商品审计任务，不伪造蓝海或 Top 10 空位。

## 8. 商业化路径

1. **研究任务包**：按“品类 × 国家”收取一次性研究额度，适合低频卖家；
2. **团队订阅**：包含任务额度、协作复核、历史报告和策略模板；
3. **持续监控订阅**：定时增量与变化检测上线后，按监控品类、国家和告警频率收费；
4. **服务商版本**：面向代运营和产业带服务商，支持工作区隔离、批量研究和白标报告。

初期不以替代成熟数据平台为目标，而是把这些平台作为上游 Provider，专注最后一公里的决策编译、验证与治理。

## 10. 给评委的一句话

对跨境商家，先机罗盘减少的是错误备货前的盲区；对技术评委，它证明的是一条 AI 决策链如何做到可执行、可追溯、可证伪、可恢复和可回滚。
