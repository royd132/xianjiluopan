# 先机罗盘 · 复赛演示脚本

> 目标时长：4 分 30 秒。前 90 秒全部围绕首单资金决策。
> 主案例：宠物自动喂食器 × 巴西（¥30,000 首批备货）；泛化验证：咖啡磨 × 美国。

## 0:00–0:35 开场：一笔真实的首单决策

打开首单决策台。

> 一个中小卖家准备把自动宠物喂食器卖到巴西，计划首批备货 ¥30,000。传统工具告诉他"市场怎么样"，先机罗盘回答"这笔钱现在能不能投"。

输入：

```
产品：宠物自动喂食器
市场：巴西 🇧🇷
决策阶段：首批备货
计划投入：¥30,000
```

点击「生成首单决策」。

## 0:35–1:10 结果第一屏：VALIDATE

6 个 Agent SSE 进度完成后，第一屏直接展示决策契约：

```
VALIDATE
当前不建议直接投入 ¥30,000

计划投入           ¥30,000
当前建议投入上限    ≤ ¥2,000
证据成熟度         4 / 5
最大未知项          真实用户购买意向尚未验证
下一步实验          30 人价格 × 痛点对比测试
实验预算            ¥2,000
```

> 先机罗盘不会因为市场数据好看就让商家直接备货。系统检查了 5 个必答问题：需求是否真实、痛点是否明确、价格是否成立、供应链外部风险是否可控、最小验证是否完成。前 4 个通过了，但第 5 个——真实用户验证——永远是缺口。这是刻意设计的硬闸门：AI 没有权限凭公开市场数据让你直接把 ¥30,000 变成库存。

展开 Stop 条件：

> 系统同时告诉卖家什么情况下结论会失效：竞品补齐核心差异、物流成本超阈值、购买意向率低于 5%。每个 Stop 条件都绑定可监测指标。

## 1:10–2:00 为什么是 VALIDATE？——四张证据卡

点击「为什么系统这么判断？」展开证据层。

> 四张分析卡不是产品本体，而是支撑投资决策的证据。

点击选品卡，展示证据链和葡语原语评论。

> 8 条证据包含 3 条巴西葡语原语评论。Qwen 模型只返回源 review ID，代码取回原文——"Gostei, mas faz muito barulho a noite"（我喜欢，但夜间太吵）。这种"喜欢但有缺陷"的结构比纯差评更适合发现差异化机会。

点击定价卡，展示锚点和测试区间。

> 以 Amazon 商品快照中位数为锚，给出首发测试区间，标注物流成本超过 15% 时重新计算。

## 2:00–2:40 百炼 Qwen Grounding 与安全闸门

展示 Trace 中 Qwen 调用记录。

> 调用阿里云百炼 Qwen 3.7 Flash。关键是 Grounding：模型被约束为只返回源评论 ID 和痛点分类，不能编造不存在的评论。每次调用记录 prompt 指纹和模型版本。Real 模式下 Qwen 失败直接拒绝任务，不静默降级。

展示 Safety Gate。

> 安全评测闸门是线上线下共享的硬门禁：证据不足、无非英语来源、缺少失效条件时直接拒绝发布。

## 2:40–3:30 验证结果回填：VALIDATE → GO

切到验证结果表单。

> 现在假设卖家完成了 30 人最小验证实验，来提交真实指标。

输入：

```
本次实际验证花费：¥1,800
样本量：35（要求 ≥30 ✓）
购买意向率：18%（要求 ≥12% ✓）
痛点确认率：40%（要求 ≥30% ✓）
```

点击提交。系统判定：

```
VALIDATE → GO

晋级门通过：样本量 35 ≥ 30；意向率 18% ≥ 12%；痛点确认率 40% ≥ 30%
当前允许投入：¥30,000（全量释放）
```

> 不是用户说"positive"就直接 Go。系统按结构化指标逐项过门：样本量、意向率、痛点确认率，每一项都必须跨过阈值。如果意向率只有 8%，系统会判定 STOP，不管用户主观怎么评价。

展示人工覆盖按钮：

> 如果系统判 STOP 但商家有额外依据，可以人工覆盖为 GO。但 system_verdict 保留为 STOP，human_override 记录为 GO——两个状态分开审计。

## 3:30–4:00 跨场景泛化

切换为"coffee grinder × US"，输入"首批小单 ¥8,000"。

> 同一个系统，切换到美国咖啡磨后，痛点变为低残粉和刻度复现，数据源变为 Amazon US 和北美运价。不是替换品类名称的固定脚本。当前已有 BR 宠物喂食器（Real）、US 咖啡磨（Hybrid）、MX 榨汁机（Mock）、US 降噪耳机（Mock）四份跨品类报告。

## 4:00–4:30 总结

> 先机罗盘是跨境新品的 AI 首单投资决策台。我们不预测爆款，我们减少"还没验证就把钱变成库存"的错误。卖家准备花 ¥30,000 首批备货，系统发现公开证据只有 4/5，拒绝直接 Go，只批准最高 ¥2,000 的验证预算；等 30 名真实用户的购买意向和痛点确认率跨过晋级门，系统才允许这笔 ¥30,000 从 VALIDATE 进入 GO。Docker 一键启动，离线模式无需 API Key 即可完整演示。
