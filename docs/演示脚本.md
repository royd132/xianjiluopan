# 先机罗盘完整 Demo 脚本

> 建议时长：5–6 分钟。案例：宠物自动喂食器 × 巴西。

## 0:00–0:40 业务问题

展示工作台并输入品类与市场。

> 跨境卖家需要同时理解趋势、竞品、当地语言评论和供应链变化。传统工具给很多数据，但最后仍要靠人把它们拼成决策。先机罗盘不再做一个数据看板，而是做一台发决策指令的机器。

## 0:40–1:20 多 Agent Runtime

点击“开始洞察”，展示实时进度。

> 任务进入 CollaborationBlackboard。Collector 先发布原始数据；原语评论、市场和供应链 Agent 并行分析；Decision Compiler 编译四卡；Safety Evaluator 最后执行硬闸门。前端看到的不是预录动画，而是 FastAPI SSE 发送的 Runtime 事件。

可以补充展示 `/docs` 或 Trace 文件，证明事件、Agent 和 Checkpoint 真实存在。

## 1:20–2:10 四张决策卡

展示选品、定价、竞争和私域四张卡。

> 选品卡建议做静音款；定价卡给出 44–52 美元区间；竞争卡要求把分贝数变成可验证卖点；私域卡进一步回答先找谁、在哪找、第一句话说什么。四张卡把洞察直接连接到行动。

## 2:10–2:55 多语言隐性痛点

点击夜间噪音气泡并展示葡萄牙语原文。

> Review Agent 直接处理原语中的让步结构。“我喜欢，但是夜间太吵”同时证明总体需求成立和局部缺陷存在，比只统计差评更适合发现差异化机会。原文始终保留供人工核查。

## 2:55–3:45 证据与反向条件

打开选品卡详情。

> 每张卡必须通过安全闸门：至少三条证据、至少一条非英语来源、私域钩子和可观测的失效条件。我们不仅告诉用户为什么建议成立，也告诉用户什么时候系统会承认自己错了。

## 3:45–4:30 Harness

展示 `.foresight/traces.jsonl`、Checkpoint 或架构图。

> Harness 统一管理 Agent 的 Trace、Memory、Checkpoint 和工具安全。任务在采集、分析和校验三个阶段保存快照，发生中断时可以从正确阶段恢复，避免使用过期上下文继续给出采购建议。

## 4:30–5:10 人工复核与自进化

点击采纳或驳回。

> 人工复核不是装饰。反馈会进入 SQLite 长期记忆，被沉淀为正向或负向案例。当前仓库已经实现反馈飞轮的前两层；等积累足够合规样本后，才进入 SFT、LoRA 或强化学习阶段。

## 5:10–5:40 离线可复现

展示 CLI 生成的 `reports/demo.json` 和测试结果。

> 为了让评审稳定复现，项目默认不依赖 API Key。离线 Mock Provider 也会完整经过同一套 Agent、Harness、闸门和反馈流程。真实数据接入只替换 Provider，不重写系统。

## 5:40–6:00 总结

> 先机罗盘用多 Agent 把全球市场数据编译成四类可执行决策，用 Harness 保证过程可治理，用证据链和反向条件建立信任，再通过人工反馈持续进化。

## 录制检查
