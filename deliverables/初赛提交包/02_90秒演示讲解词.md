# 先机罗盘 90 秒演示讲解词

## 0:00-0:12 业务问题

跨境卖家真正高风险的时刻，是准备付样品费、开模、备货和投入广告的时候。数据很多，但最后的进入决策仍依赖经验。

## 0:12-0:25 产品入口

先机罗盘让卖家输入品类和目标国家。系统首先检查当前场景的数据覆盖范围，真实数据不足时会明确拒绝，不会自动换成演示数字。

## 0:25-0:42 四张决策卡

六类 Agent 把价格、评论、贸易、汇率和供应链信号编译成四张卡，回答做什么、卖多少、怎么竞争，以及先找谁验证。

## 0:42-0:57 原语痛点

Review Agent 直接处理多语言原始评论。模型只返回支持痛点的源记录 ID，引用原文由代码取回，避免生成无法核查的用户证言。

## 0:57-1:10 证据与实时性

每条证据区分发生时间和读取时间，也标记目标市场、跨市场或历史基线。汇率、物流或竞品信号越过阈值后，可以只重算受影响的决策卡。

## 1:10-1:22 Harness

Harness 负责 Trace、Checkpoint、工具权限和组件快照。Provider 可以热更新，旧任务仍锁定原版本，建议可以恢复、审计和复现。

## 1:22-1:30 总结

先机罗盘不替卖家自动下单，而是在不可逆投入之前，把“我感觉能卖”变成“哪些证据支持、先验证什么、什么情况下停止”。
